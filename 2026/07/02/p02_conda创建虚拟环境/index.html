p02_conda创建虚拟环境

列出当前环境中已安装的包

  • conda list

列出当前存在的所有环境

  • conda env list

为 conda 添加国内镜像源

  • conda config –add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/

移除指定的 channel

  • conda config –remove channels

恢复默认源

  • conda config –remove-key channels

查看当前 channels 配置状态

  • conda config –show channels

搜索指定的包

  • conda search

创建 Python 虚拟环境

  • conda create -n python=x.x
  • 解释：创建 Python 版本为 x.x，名字为 your_env_name 的虚拟环境
  • 创建爬虫环境conda create -n crawler Python=3.10

激活指定的环境

  • conda activate

退出当前环境

  • conda deactivate

在当前环境中安装包

  • conda install =x.x

在指定环境中安装包

  • conda install -n =x.x

删除当前环境中的某个包

  • conda remove

删除指定环境中的某个包

  • conda remove -n

删除指定的虚拟环境

  • conda remove -n –all

在虚拟环境中安装uv

pip install uv
