p05_运算符 & 优先级

运算符、优先级

算术运算符

运算符 描述
+ 加
- 减
* 乘
/ 除
% 取模（求余数）
** 幂
// 整除（ 相当于 / 的结果再向下取整）

比较运算符

  • 判断两个对象值的大小关系
  • 返回布尔值：True，False
运算符 描述
== 等于
!= 不等于
> 大于
< 小于
>= 大于或等于
<= 小于或等于

赋值运算符

运算符 描述
= 简单的赋值运算符
+= 加法赋值运算符
-= 减法赋值运算符
*= 乘法赋值运算符
/= 除法赋值运算符
%= 取模赋值运算符
**= 幂赋值运算符
//= 取整赋值运算符

增强赋值

  • 增强赋值在条件符合的情况下（如：操作数是一个可变数据）会以inplace的方式来进行处理，而普通赋值则会以新建的方式进行处理。

id(object)

  • 返回 object 的唯一标识符（内存地址）
  • 两个对象具有相同的id值，说明它们为同一对象

+、 的拼接操作*

  • +、+=、*、*= 还支持字符串、列表、元组的拼接操作

基本序列赋值

  • 格式： a, b, c, … = iterable
  • 将iterable的元素分别赋值给对应变量，元素和变量个数需要一致

多目标赋值

  • 将一个对象同时赋值给多个变量。

逻辑运算符

运算符 描述
and 布尔”与”（左边bool判定为False，返回左边；否则返回右边）
or 布尔”或”（左边bool判定为True，返回左边；否则返回右边）
not 布尔”非”（判定为False，返回 True；判定为True，返回 False）

短路机制

  • 在逻辑表达式中，由于and和or的特点，表达式中的部分内容可能不会执行

all(iterable)

  • 如果 iterable 的所有元素 bool 判定都为 True，则返回 True
  • 如果 iterable 为空，也返回 True

any(iterable)

  • 如果 iterable 中存在至少一个元素 bool 判定为 True，则返回 True
  • 如果 iterable 为空，也返回 False

成员运算符

  • 判断某个对象是否为指定 iterable 的元素
  • 返回布尔值：True，False
运算符 描述
in 在其中
not in 不在其中

身份运算符

  • 判断两个标识符是不是引用自同一个对象
  • 返回布尔值：True，False
运算符 描述
is 类似于判断 id(a) == id(b)
is not 类似于判断 id(a) != id(b)

运算符优先级

以下表格列出了从高到低优先级的常用运算符：

运算符 描述
** 指数
* / % // 乘，除，求余数和取整除
+ - 加法、减法
<= < > >= 比较运算符
== != 等于运算符
%= /= //= -= += *= **= 赋值运算符
is is not 身份运算符
in not in 成员运算符
not and or 逻辑运算符
= 简单赋值运算符
